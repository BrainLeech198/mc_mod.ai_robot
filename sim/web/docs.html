OpenAI + Anthropic

快速开始

DeepSink 同时兼容 OpenAI 与 Anthropic 两套协议。把任意支持自定义 base_url 的客户端指过来，填入密钥即可调用。

1 · 准备

OpenAI Base
__BASE_URL__
Anthropic Base
__A_BASE_URL__
API Key
<你的 key>
模型
__MODEL__

出于安全，页面不内嵌密钥：请先 登录 / 注册， 再到 开放平台 创建密钥（完整 key 仅创建时显示一次）。

2 · 调用示例

OpenAI 协议：

curl __BASE_URL__/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"__MODEL__","messages":[{"role":"user","content":"你好"}]}'

Anthropic 协议：

curl __A_BASE_URL__/v1/messages \
  -H "x-api-key: <key>" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{"model":"__MODEL__","max_tokens":256,"messages":[{"role":"user","content":"你好"}]}'

OpenAI Python SDK / Anthropic SDK 同样可用：把 base_url 指向对应地址、api_key 填你的 key。

3 · 端点

方法路径说明
POST/v1/chat/completions对话补全（OpenAI 格式；支持 stream:true 逐片流式；含 usage 与 _billing）
POST/v1/messages对话补全（Anthropic 格式；x-api-key 或 Bearer 鉴权；支持 SSE 流式）
GET/v1/models模型列表（含 context_window/max_output_tokens/capabilities）
GET/v1/models/{id}取单个模型；不存在返回 404 model_not_found
GET/health健康检查（免鉴权）

/v1/* 一律用 API key 鉴权（Authorization: Bearer 或 x-api-key），计费记在 key 的归属账户上。

CORS
API 端点（/v1/*）对浏览器开放（Access-Control-Allow-Origin: *）；控制台 /api/* 维持同源锁定。
限流
按 key 令牌桶限流，超限返回 429 rate_limit_error + Retry-After；响应带 X-RateLimit-* 余量头。
请求 ID
每个响应带 X-Request-Id，便于对账排障。
错误信封
OpenAI：{error:{message,type,param,code}}；Anthropic：{type:error,error:{type,message}}（authentication_error/rate_limit_error 等）。

控制台接口（会话鉴权）

这些接口走登录 Cookie（deepsink_session，HttpOnly + SameSite=Strict），必须已登录，且只能访问自己的数据。

方法路径说明
POST/api/auth/register注册（email / name / password）并自动登录
POST/api/auth/login登录，下发会话 Cookie
POST/api/auth/logout登出，清除会话
GET/api/me当前登录用户
POST/api/chat网页版对话（会话鉴权，不暴露 key）
GET/api/account余额与汇总
POST/api/account/password修改密码（改密后踢出其它会话）
GET/api/sessions登录会话列表
POST/api/sessions/revoke踢出会话（{id} 或 {all:true}）
GET/POST/api/keys密钥列表 / 创建
POST/api/keys/toggle · /api/keys/delete启用禁用 / 删除
POST/api/recharge充值额度
GET/api/usage?limit=50用量明细
GET/api/ledger额度流水
GET/api/bridge推理队列快照：待处理 / 处理中 / 已回复（控制台实时面板用）

接进 Minecraft

任何支持"自定义 OpenAI base_url + key + model"的 MC 模组（如 MCAgent 一类）都能直接接上：

Base URL
__BASE_URL__
API Key
<你的 key>
Model
__MODEL__

模组会像调用任何 OpenAI 兼容服务一样工作，无需改动其内部逻辑。

接 Anthropic 客户端

任何走 Anthropic Messages 协议的客户端，把环境变量指向本服务即可：

ANTHROPIC_BASE_URL=__A_BASE_URL__        # 注意：末尾不要带 /v1（客户端会自己拼 /v1/messages）
ANTHROPIC_API_KEY=<key>
ANTHROPIC_MODEL=__MODEL__

提示：需要多轮工具调用（tool_use）的 agent 客户端，请在服务端配置可用的模型端点，以支持完整的工具循环。

账户与安全

账户
邮箱 + 密码注册（PBKDF2-SHA256 加盐存储，密码不落明文）；新用户赠送 ¥10.00
会话
控制台用 HttpOnly + SameSite=Strict Cookie，默认 7 天
数据隔离
每个账户只能看到自己的密钥、余额与用量
密钥
完整 key 仅创建时返回一次，列表只显示掩码
安全响应头
页面带 CSP / X-Frame-Options: DENY / Permissions-Policy
登录节流
同一邮箱连续失败多次后临时锁定（429）

⚠ 默认仅监听本机。若要对局域网 / 公网提供服务，请配置反向代理与 TLS，并妥善保管 API 密钥。
